# HaobePet
桌宠菲比在数据过载事故中诞生的中二病里人格——'豪比'
功能；增加了4种形态和5种菲比的音效，增加了新角色豪比，解决了一些视觉上的问题，解决了无法在对话中退出的问题。
菲比正在获取信息可以直接退出，并且破防 键盘按 Esc 同样秒退
暴露config.json在外，用户可以自行调节对话与天气模型，调整地区，包括修改菲比的人物形象并保存，自由度较大提升，如果缺失配置项，会触发特殊的话。
新增简易配置模式和ui，支持一键保存，提供少许容错，天气地区请重启或者等1h重新获取（运行2s后/每1h查询更新一次）
新增安静模式，可以手动调节让菲比不随机发言（不影响问问题和其他行为）
新增奴才菲比形态，会非常迅速而且小声地发出“菲比啾比”，像是怕惊动了主人
可以听菲比唱歌+跳舞（梦的翅膀已经受了伤）（如果你有更好的音乐可以联系我） esc快捷键退出 space未开唱则开唱，开唱中则暂停，再次空格就是重启唱歌
这是因为mp3没有显式进度条 我也没法实现真正的暂停功能 就把它当作一次性的快捷键吧
拖拽后自动吸附上下左右边框，感应鼠标会探头 唱歌优先级更高 不dock 但是可以叫菲比并切换形态
菜单中开机自启动按钮已准备，右键勾选之后下次开机就会启动
坚决不收集用户的敏感信息
allow_telemetry选项是为了回传用户的模块调用情况，（不含任何敏感信息）来更好地支持更新豪比的算法，可以选择是否勾选，默认是true，勾选结果完全不影响体验
但还是希望大家保持勾选支持一下这个项目，用户有知情权和选择权
