## 📖 项目简介

**HaobiPet** 是一个运行于 Windows 桌面的轻量化桌面宠物应用。它不仅拥有萌趣灵动的多状态动作与屏幕边缘吸附能力，更接入了大语言模型（LLM）内核与独特的**中二傲娇人设**。

无论你是需要一位桌面工作陪伴者，还是想随手召唤 AI 进行解惑、吐槽、代码解析，菲比/豪比都能以独特的因果律姿态随时为你效劳。

---

## ✨ 核心特性

- 🎭 **拟真与趣味状态机**：
  - 拥有待机闲置（IDLE）、互动点击（CLICK）、随机起舞（SING & DANCE）等多种动作姿态。
  - **屏幕边缘停靠（Docking）**：拖拽至屏幕边缘自动折叠隐蔽，探头张望，绝不干扰正常办公与全屏工作。
- 🧠 **大模型多轮思维（因果律会话）**：
  - **滑动上下文记忆**：支持 1~5 轮会话记忆滑动窗口（默认 3 轮），多轮问答不串台，人设法则永久置顶。
  - **打字机灵动反馈**：气泡打字机效果逐字显现，拒绝生硬的一瞬间文字贴脸。
  - **兼容一切 OpenAI 标准接口**：原生预设 DeepSeek、通义千问（Qwen）等主流平台，亦支持自定义端点与自建 Ollama / LocalAI。
- 📋 **混沌灵犀感知（剪贴板互动）**：
  - 本地事件驱动监听，识别链接、代码、问句及中二暗号，触发即时台词彩蛋（零 Token 消耗）。
  - **隐私严密防御**：内置敏感模式正则拦截，不扫描密码、Token 与敏感长文本；严格遵守本地解析规范，绝不私自上传剪贴板文字。
- ⚙️ **「因果律核芯裁决阵列」全屏配置控制台**：
  - 一键图形化修改 API Key、模型代号、城市天气坐标与记忆轮数，无需手动折腾 JSON 文件。
  - 自由开关匿名遥测统计与剪贴板感知功能。
- 🚀 **绿色轻量，单文件即开即用**：
  - 无需繁琐配置 Python 运行环境，开箱即用，支持一键开机自启。

## 🎮 玩法与交互指南

| 操作方式 | 触发效果 / 功能描述 |
| :--- | :--- |
| **左键点击桌宠** | 触发交互动画（CLICK），打断发呆并做出反应 |
| **按住左键拖拽** | 自由移动桌宠；拖拽靠近屏幕边缘时自动吸附折叠 |
| **右键呼出菜单** | 唤起控制面板：开启因果律配置、查阅天气、切换静音/自启等 |
| **选择唤起对话** | 弹出通灵对话框，向菲比输入你的困惑与指令 |
| **复制特定文字** | 触发剪贴板彩蛋（如复制代码片段、URL 链接、中二关键词） |
| **自行修改人设** | 我的菲比我做主，prompt支持自己修改 |
| **[ESC] 键** | 退出全屏配置阵列面板 |

## 🛠️ 快速上手

### 1. 下载与运行
前往 [Releases 页面](https://github.com/220017-18/HaobePet/releases) 下载最新版本的 `HaobiPet.exe`，放置于任意文件夹后双击运行即可。

> **提示**：首次启动将在本地系统配置目录自动生成初始配置文件。

### 2. 注入通灵秘钥 (API 配置)
1. 右键点击桌宠，选择 **「因果律核芯裁决阵列 (配置)」**。
2. 在预设下拉菜单中选择你习惯的服务商（例如：`DeepSeek 官方` 或 `SiliconFlow`）。
3. 填入你的 **API Key (通灵秘钥)**。
4. （可选）设定你的 **观测坐标 (城市)**，例如：`杭州`、`北京`、`兰州`。
5. （可选）调整 **记忆因果锚定 (1~5 轮)** 与人设咒文。
6. 点击底部 **「注入因果律 (保存设置)」**，秘钥立即生效！

## ⚙️ 进阶配置与隐私说明

### 因果律上下文记忆机制
- 系统严格遵循滑动窗口机制：保留最近 $n$ 轮问答（$2n$ 条消息），超出轮数将自动裁汰最旧信息。
- 人设系统提示词（System Prompt）永久锚定在首部，确保无论聊多久，豪比/菲比的角色性格永不崩溃。

### 隐私与安全合规
- **完全透明的剪贴板监听**：剪贴板感知采用本地匹配与正则过滤，仅用于触发本地台词，不记录、不回传明文剪贴板数据。可在设置中一键彻底关闭。
- **匿名遥测（可选）**：仅用于上报匿名会话时长、功能点击频次与错误捕获，不包含任何私人会话内容与账号密码；支持在配置面板中自由取消勾选。

## 🚀 下载与使用
